# Portfólio — Antônio Gabriel

Site estático responsivo feito em HTML, CSS e JavaScript puro.

## Como visualizar
1. Extraia o ZIP.
2. Abra a pasta `portfolio_antonio_gabriel`.
3. Abra `index.html` no navegador.

## Antes de publicar
- Troque `SEU-EMAIL@EXEMPLO.COM` pelo seu e-mail profissional.
- Troque os links genéricos do LinkedIn e GitHub pelos seus perfis.
- Inclua links para repositórios e demonstrações reais dos projetos.
- Revise os nomes, datas, descrições e o status de cada projeto.
- Não apresente ideias/conceitos como projetos concluídos.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `portfolio`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e acesse o endereço informado pelo GitHub Pages.
